# ReciptFlow

**Gestisci le tue ricevute in modo semplice e veloce**

> **Progetto in fase di sviluppo iniziale** - Questa è una versione prototipale del progetto.

## Cosa fa

ReciptFlow è un'app mobile per digitalizzare e organizzare le tue ricevute fiscali:

- Scatta foto alle ricevute
- Estrazione automatica dei dati tramite AI
- Visualizza statistiche delle spese
- Cerca e filtra le ricevute

## Tecnologie

- **React Native** - Framework mobile cross-platform
- **Expo** - Toolchain per sviluppo rapido
- **Claude AI** - Analisi intelligente delle ricevute
- **AsyncStorage** - Salvataggio locale dei dati

## Stato del progetto

Il progetto è attualmente in **fase di prototipazione**. Funzionalità implementate:

- Interfaccia base di navigazione
- Cattura foto ricevute
- Integrazione API Claude per OCR
- Salvataggio locale dati
- Dashboard con statistiche base

## Installazione (per sviluppatori)

```bash
# Clona il repository
git clone https://github.com/riccardocasalanguida/ReceiptFlow

# Installa le dipendenze
cd reciptflow
npm install

# Avvia l'app
npx expo start
```
